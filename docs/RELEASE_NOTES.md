Gemini Gateway для macOS 13+ на Apple Silicon.

Поддерживает Antigravity Desktop и IDE через HTTP/SOCKS5, Happ и AmneziaWG. Исходники, сборка и loopback-тесты находятся в репозитории; ZIP содержит только Gateway, без Antigravity и пользовательских профилей.

Как начать:

1. Распакуйте ZIP и откройте Gemini Gateway.app.
2. Подключите VPN, выберите маршрут и нажмите «Проверить маршрут» → «Применить маршрут».
3. Запустите Desktop или IDE кнопкой Gateway и войдите в отдельном профиле.

Приложение подписано ad hoc, без Developer ID и нотариализации Apple. macOS может попросить разрешить открытие через «Конфиденциальность и безопасность». Глобально отключать защиту не требуется.

SHA-256 архива опубликован в SHA256SUMS. Совпадение хеша подтверждает целостность скачанного файла, а не отсутствие уязвимостей.

Региональные и тарифные ограничения на стороне Google могут сохраняться. Подробности работы с локальной копией Desktop, конфиденциальности и ограничений — в README.
